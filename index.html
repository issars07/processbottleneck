System Setup

Applying raw materials or a steady-state start resets the run. Buffer limits can be changed at any time, even while running.

Raw Materials

How many units the run processes in total (1–1000).

Buffer Space

When a buffer is full, the stage before it stops working completely: it won't start a new unit, and a unit in progress pauses. The stage flashes "Blocking" until space frees up.

Steady-State Start

WIP is taken out of the raw-material total. "Suggest WIP" fills the buffers before the bottleneck and empties the ones after it, which is where a long-running line settles.
